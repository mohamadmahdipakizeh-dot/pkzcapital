Project Overview

PKZ Capital is a website project designed and built using WordPress and Elementor. Its structure focuses on presenting services, providing essential information, and making contact details easily accessible.

Features

- Responsive layout for mobile and tablet devices
- Service information
- Contact details and contact form
- Visual animations and interactions
- Customized page layouts and styling
- Contact and inquiry section

Technologies

- WordPress
- Elementor
- HTML
- CSS
- JavaScript
- GitHub Pages for static deployment

My Contributions

- Prepared the main website content
- Selected and prepared images and visual assets
- Customized CSS styling
- Debugged code and refined page presentation
- Prepared and deployed the static website version
